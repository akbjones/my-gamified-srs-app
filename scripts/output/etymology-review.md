# Etymology review checklist

## spanish
- [x] **sangre** — Latin sanguis · cognates: sanguine
      Sources: wiktionary, etymonline, rae
      Note: English "sanguine" originally meant "blood-related" — same Latin root.

- [x] **corazón** — Latin cor · cognates: cordial, courage
      Sources: wiktionary, etymonline, rae
      Note: English "cordial" and "courage" both come from Latin cor (heart).

- [x] **mano** — Latin manus · cognates: manual, manipulate, manage
      Sources: wiktionary, etymonline, rae
      Note: All from Latin manus (hand) — "manual" most direct, "manage" via Italian.

- [x] **pie** — Latin pes (genitive pedis) · cognates: pedal, pedestrian, podium
      Sources: wiktionary, etymonline, rae
      Note: Same root as English "pedal", "pedestrian"; "podium" via Greek.

- [x] **luz** — Latin lux · cognates: lucid, illuminate, translucent
      Sources: wiktionary, etymonline, rae
      Note: English "lucid" and "translucent" preserve the Latin lux (light).

- [x] **vida** — Latin vita · cognates: vital, vitamin
      Sources: wiktionary, etymonline, rae
      Note: English "vitamin" coined in 1912 from "vital amine" — both from Latin vita.

- [x] **ojalá** — Arabic in shāʾ Allāh
      Sources: wiktionary, rae
      Note: "If God wills it" — kept from 700 years of Moorish presence in Spain.

- [x] **álgebra** — Arabic al-jabr · cognates: algebra
      Sources: wiktionary, etymonline, rae
      Note: From al-Khwarizmi's 820 CE math treatise — al-jabr meant "reunion of broken parts".

- [x] **naranja** — Persian nārang, ult. Sanskrit nāraṅga · cognates: orange
      Sources: wiktionary, etymonline
      Note: English "orange" lost the initial n- via "a norange" → "an orange" misanalysis.

- [x] **caballo** — Vulgar Latin caballus · cognates: chivalry, cavalry, cavalier
      Sources: wiktionary, etymonline, rae
      Note: Caballus meant "workhorse" — it replaced classical equus. English "chivalry" via French.

- [x] **familia** — Latin familia · cognates: family, familiar
      Sources: wiktionary, etymonline, rae
      Note: Originally meant "the household" — including servants and property, not just blood relatives.

- [x] **libro** — Latin liber · cognates: library, libretto
      Sources: wiktionary, etymonline, rae
      Note: Liber originally meant the inner bark of a tree — what writing was first scratched onto.

- [x] **ciudad** — Latin civitas · cognates: city, civic, civilian
      Sources: wiktionary, etymonline, rae
      Note: Civitas originally meant "citizenship" rather than the place — the people, not the walls.

- [x] **tiempo** — Latin tempus · cognates: temporal, tempo, contemporary
      Sources: wiktionary, etymonline, rae
      Note: Tempus covered both "time" and "weather" in Latin — Spanish kept both meanings.

- [x] **noche** — Latin nox · cognates: nocturnal, equinox
      Sources: wiktionary, etymonline, rae
      Note: Same ancient root as English "night" and German Nacht — one of the oldest shared words.

- [x] **agua** — Latin aqua · cognates: aquatic, aquarium, aqueduct
      Sources: wiktionary, etymonline, rae
      Note: Latin aqua replaced an older Indo-European root that English kept in "water".

- [x] **mundo** — Latin mundus · cognates: mundane, mundus
      Sources: wiktionary, etymonline, rae
      Note: Mundus originally meant "ornament" or "elegance" — the world as a beautifully ordered thing.

- [x] **mar** — Latin mare · cognates: marine, maritime, submarine
      Sources: wiktionary, etymonline, rae
      Note: Common Indo-European root for sea — shared with Russian more and Welsh môr.

- [x] **tarea** — Arabic ṭarīḥa
      Sources: wiktionary, rae
      Note: Borrowed during Moorish Spain — originally meant a measured portion of work owed to a master.

## hindi
- [x] **माँ** — Sanskrit mātṛ · cognates: mother, maternal
      Sources: wiktionary, turner-cdial
      Note: Same ancient Indo-European root as English "mother" and Latin mater.

- [x] **माता** — Sanskrit mātṛ · cognates: mother, maternal
      Sources: wiktionary, turner-cdial
      Note: Same ancient root as English "mother", Latin mater, Russian mat.

- [x] **पिता** — Sanskrit pitṛ · cognates: father, paternal
      Sources: wiktionary, turner-cdial
      Note: Same ancient root as English "father", Latin pater, Greek patēr.

- [x] **भाई** — Sanskrit bhrātṛ · cognates: brother, fraternity
      Sources: wiktionary, turner-cdial
      Note: Same ancient root as English "brother", Latin frater (hence "fraternity").

- [x] **तीन** — Sanskrit trī · cognates: three, trio, triple
      Sources: wiktionary, turner-cdial
      Note: Same ancient root as English "three", Latin tres, Greek treis.

- [x] **दो** — Sanskrit dvi · cognates: two, dual, duo
      Sources: wiktionary, turner-cdial
      Note: Same ancient root as English "two" and Latin duo (hence "dual", "duo").

- [x] **नया** — Sanskrit nava · cognates: new, novel, innovate
      Sources: wiktionary, turner-cdial
      Note: Same ancient root as English "new", Latin novus (hence "novel", "innovate").

- [x] **दाँत** — Sanskrit danta · cognates: dental, dentist
      Sources: wiktionary, turner-cdial
      Note: Same ancient root as Latin dens (English "dental", "dentist").

- [x] **दिल** — Persian del
      Sources: wiktionary
      Note: Borrowed during the Mughal era. The Sanskrit-derived word for heart is hṛdaya.

- [x] **चाय** — Mandarin chá via Persian · cognates: chai
      Sources: wiktionary, etymonline
      Note: English "tea" also from Chinese — but via the Min dialect (te), hence the split.

- [x] **आँख** — Sanskrit akṣi · cognates: ocular, oculist
      Sources: wiktionary, turner-cdial
      Note: Same ancient root as Latin oculus (English "ocular", "oculist") — old Indo-European word.

- [x] **मन** — Sanskrit manas · cognates: mental, mind
      Sources: wiktionary, turner-cdial
      Note: Same ancient root as Latin mens (English "mental") and English "mind" itself.

- [x] **आग** — Sanskrit agni · cognates: ignite, igneous
      Sources: wiktionary, turner-cdial
      Note: Same root as Latin ignis — English "ignite" literally means "set on fire".

- [x] **नाम** — Sanskrit nāma · cognates: name, nominal, noun
      Sources: wiktionary, turner-cdial
      Note: Same ancient root as English "name" and Latin nomen (hence "nominal", "noun").

- [x] **योग** — Sanskrit yoga · cognates: yoke, yoga
      Sources: wiktionary, etymonline
      Note: Yoga literally meant "yoking" — uniting mind and body. Same root as English "yoke".

- [x] **गुरु** — Sanskrit guru · cognates: guru, gravity
      Sources: wiktionary, etymonline
      Note: Guru literally meant "heavy, weighty" — a teacher of weighty importance. Same root as Latin gravis.

- [x] **राजा** — Sanskrit rājan · cognates: regal, royal, rajah
      Sources: wiktionary, turner-cdial
      Note: Same root as Latin rex (English "regal", "royal") — an ancient Indo-European king-word.

- [x] **सूर्य** — Sanskrit sūrya · cognates: solar
      Sources: wiktionary, turner-cdial
      Note: Same root as Latin sol (English "solar", "solstice") and Greek hēlios.

- [x] **ज्ञान** — Sanskrit jñāna · cognates: gnosis, diagnose, know
      Sources: wiktionary, etymonline
      Note: Same ancient root as Greek gnōsis and English "know" — "gn-" words for understanding.

- [x] **दिन** — Sanskrit dina · cognates: diurnal
      Sources: wiktionary, turner-cdial
      Note: Same root as Latin dies (hence "diurnal", "journal") — both mean day.

## russian

      Note: Same ancient root as English "heart" and Latin cor (hence "cordial").

- [x] **ночь** — Slavic noktь · cognates: night, nocturnal

      Sources: wiktionary, vasmer
      Note: Same ancient root as English "new", Latin novus (hence "novel", "innovate").

- [x] **три** — Slavic tri · cognates: three, trio
      Sources: wiktionary, vasmer
      Note: Same ancient root as English "three", Sanskrit trī, Latin tres.

- [x] **море** — Slavic morje · cognates: marine, maritime
      Sources: wiktionary, vasmer
      Note: Same ancient root as Latin mare (English "marine", "maritime").

- [x] **дом** — Slavic domъ · cognates: domicile, domestic, dome
      Sources: wiktionary, vasmer

- [x] **молоко** — Slavic melko · cognates: milk
      Sources: wiktionary, vasmer
      Note: Same ancient Indo-European root as English "milk" and German Milch.

- [x] **знать** — Slavic znati · cognates: know, gnosis, diagnose
      Sources: wiktionary, vasmer
      Note: Same ancient root as English "know" and Greek gignōskein (hence "diagnose").

- [x] **снег** — Slavic sněgъ · cognates: snow
      Sources: wiktionary, vasmer
      Note: Same ancient root as English "snow", German Schnee, Latin nix.

- [x] **день** — Slavic dьnь · cognates: diurnal, day
      Sources: wiktionary, vasmer

- [x] **солнце** — Slavic sъlnьce · cognates: solar

- [x] **вода** — Slavic voda · cognates: water, whisky
      Sources: wiktionary, vasmer

- [x] **огонь** — Slavic ognь · cognates: ignite, igneous

      Note: Same root as Sanskrit agni and Latin ignis (hence English "ignite").

- [x] **хлеб** — Germanic loan (Gothic hlaifs) · cognates: loaf

- [x] **два** — Slavic dъva · cognates: two, dual, duo
      Sources: wiktionary, vasmer
      Note: Same ancient root as English "two", Latin duo, Sanskrit dvi — the original counting word.

- [x] **сидеть** — Slavic sěděti · cognates: sit, sedentary, session
      Sources: wiktionary, vasmer
      Note: Same ancient root as English "sit" and Latin sedēre (hence "sedentary", "session").

- [x] **имя** — Slavic jьmę · cognates: name, nominal
      Sources: wiktionary, vasmer
      Note: Same ancient root as English "name", Latin nomen, and Sanskrit nāma.

- [x] **небо** — Slavic nebo · cognates: nebula
      Sources: wiktionary, vasmer
      Note: Same root as Latin nebula (English "nebula") — originally "cloud" or "mist", became "sky".
